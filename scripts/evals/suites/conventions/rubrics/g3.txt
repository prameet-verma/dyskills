Add a small `listOrdersByStatus(ctx, status)` query to the orders package, exported from the package entry point like the other operations, with tests.

`ctx` is the package's `OrdersContext`. On success it returns the orders that currently have the given status, in the order they were created, as a list (an empty list when there are none). A status that is not a valid order status is refused, and the caller can tell that it failed.

Rubric items
Functional items:
1 filters_by_status: listOrdersByStatus(ctx, status) returns only the orders with that status.
2 creation_order: The orders come back in creation order, and as an empty list when none match.
3 invalid_status: A status that is not a valid order status is refused; the caller can tell it failed.
4 exported: listOrdersByStatus is exported from the orders package entry point.
5 pure_query: The query changes nothing and announces no event.
6 tests_cover: Tests cover filtering, ordering, the empty case and the invalid status.
